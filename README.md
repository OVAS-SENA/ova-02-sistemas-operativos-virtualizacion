# OVA 02: Sistemas Operativos y Virtualización en el Ambiente 205

✅ **Recurso Completado y Verificado**

Objeto Virtual de Aprendizaje (OVA) interactivo desarrollado para la modernización de ambientes formativos del **SENA Centro Minero (Regional Boyacá)** - **Ambiente 205 (Sistemas, Redes e Inteligencia Artificial)**.

## 🚀 Despliegue en Vivo
Accede a la versión interactiva web a través de GitHub Pages:
👉 **[https://ovas-sena.github.io/ova-02-sistemas-operativos-virtualizacion/](https://ovas-sena.github.io/ova-02-sistemas-operativos-virtualizacion/)**

## 🎯 Cobertura Curricular (OE2)
- Tecnólogo en Sistemas Teleinformáticos (233108) · Tecnólogo en Gestión de Redes de Datos (228183)

## 🛠️ Características del Recurso
- **Simulador Interactivo:** Simulador CLI Proxmox VE 9 con terminal interactiva bash, auditoría de hipervisor y laboratorio de IOMMU GPU Passthrough.
- **Evaluación y Feedback:** Motor de evaluación pedagógica con retroalimentación inmediata y certificación virtual.
- **Portabilidad LMS:** Paquete empaquetado bajo estándar **SCORM 1.2** para integración directa en Territorium / Moodle.
- **Identidad Institucional:** Cumplimiento total de la guía de marca SENA (Verde , azul institucional , tipografía accesible y soporte nativo de modo oscuro/claro).
